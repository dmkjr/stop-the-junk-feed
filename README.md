# Block The Junk by SiteKings public phone feed

This repository mirrors a reviewed subset of community phone reports for tools that screen unwanted calls. Use the [live CSV](https://junk.sitekings.net/v1/public/blocklist.csv) for the current list.

| Column | Description |
| --- | --- |
| phone_number | US phone number in E.164 format |
| report_count | Number of accepted reports |
| distinct_installations | Number of different app installations that reported the number |

Use each download as a full replacement. A number can leave the feed after a correction, withdrawal, or change in corroboration. Check caller context before blocking. Caller ID can be spoofed, and these records do not identify a caller. For a correction or removal request, [contact SiteKings](https://sitekings.net/contact/) with the affected number.
